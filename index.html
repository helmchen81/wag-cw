Changelog

Version 3.6.0

  • Declared the original software and documentation as open source under the MIT License.
  • Added visible GitHub repository and license links.
  • Added CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, NOTICE and CITATION files.
  • Documented third-party contest information, callsign data considerations and security reporting.

Version 3.5.1

  • Admin-panel patch workflow validated with manifest and SHA-256 file checks.

Version 3.5.0

  • Added Admin link in the footer, opening in a new window.
  • Made the leaderboard more compact, especially on smartphones.
  • Added German/English language selection throughout the admin backend.
  • Extended secure patch allowlist for controlled admin UI updates.
  • Reviewed formatting and code structure across frontend and admin files.

Version 3.4.1

  • Admin login changed to a two-step call-first flow.
  • New-password prompts are shown only during first setup.
  • Fixed CSRF session handling for installations in subdirectories.

Version 3.4.0

  • Added protected /admin area with first-run setup for DG8WA or DF9ZV.
  • Added leaderboard moderation, GDPR erasure, audit log and secured manifest-based patch installation.
  • Admin password hash is stored in admin/data/admin-auth.json and can be reset by deleting that file over SSH.

Version 3.3.0

  • Leaderboard now lists individual submissions instead of one aggregated row per callsign.
  • Default TOP 10 can be expanded to 25, 50 or 100 entries.
  • Clicking a callsign opens all submissions for that call, including its internal TOP 10 ranking.
  • The API maintains overall TOP 50 and per-call TOP 10 ranks.

Version 3.2.5

  • Fixed partial calls and callsigns whose entered fragment begins with a digit.
  • Call fragments are now normalized consistently for F2, F5 and F7 and can match at any position.
  • Normalized pileup to an integer from 1 to 10 before scoring and leaderboard submission.
  • Leaderboard API now safely normalizes missing or malformed pileup values instead of rejecting mobile submissions.

Version 3.2.4

  • Added Submit to Leaderboard directly to the TIME IS UP scoring panel without dismissing it.
  • Reworked QSB: shorter fade cycles and a guaranteed audible floor through 50% QSB.
  • Changed DX serial distribution so 92% are 001–999 and 8% are 1000–1999; selected Cut Numbers still apply on air.
  • Added 17 supplied German callsign/DOK records and updated existing matches without duplicates.

Version 3.2.3

  • Renamed the application to DG8Wa(stl's) WAG/CWA cw test trainer.
  • Privacy, storage notice and source information now follow the selected UI language.
  • Reviewed and expanded translations for the header, contest style controls, Battle leaderboard, privacy actions and current settings.
  • Grouped WAG/CWA Style, Help and Privacy into a visually distinct primary-control cluster in the header.

Version 3.2.2

  • Fixed the storage notice controls and browser detection by deferring script execution until the complete page is parsed.
  • Added the supplied operator and self-hosting details to Privacy & Sources.
